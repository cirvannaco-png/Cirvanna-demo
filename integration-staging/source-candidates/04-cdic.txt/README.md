# CDIC v4.0 - Cognitive Decision Intelligence Core

Production-ready decision intelligence engine with FastAPI.

## Features

- **High Performance**: Multi-threaded option generation, caching, and optimized algorithms
- **Thread Safety**: Distributed locking, RLock patterns, and thread-local random generators
- **Production Ready**: Circuit breakers, rate limiting, monitoring, and health checks
- **Security**: Input validation, secure hashing, and environment-based configuration
- **Observability**: Prometheus metrics, structured logging, and performance monitoring
- **Role Separation**: CDIC only provides options, Tari controls flow (Spec 2.1)
- **Clarification Fatigue Control**: Budget-based clarification limiting (Spec 2.2)
