# Hybrid Identity Decision Engine

A brilliant fusion of a bulletproof deterministic core and a production‑ready engine.  
Inspired by the monolithic “law” and the modular production engine.

## Features
- **Absolute determinism** – same input → same output, forever.
- **Zero‑throw guarantee** – always returns a valid decision.
- **Caching** – LRU cache with TTL for high throughput.
- **Circuit breakers** – resilience against external failures.
- **Metrics** – latency percentiles, cache hit rate, error distribution.
- **Batch processing** – handle multiple requests efficiently.
- **Beauty AI integration** – ready for virtual try‑on validation.
- **Immutable core** – the core logic is versioned and unchangeable.
