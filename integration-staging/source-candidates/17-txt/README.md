# Xyra V6 – Full Fashion Intelligence System

Xyra is a unified platform integrating:
- **Conversational AI** (intent parsing, multi-turn dialogue)
- **Semantic Product Retrieval** (hybrid search: BM25 + vectors + behavioral boost)
- **Outfit Composition** (compatibility graph, constraints, variations)
- **XARI Ranking Engine** (contextual bandit, multi‑objective scoring)
- **Virtual Try‑On** (async GPU rendering, queue management)
- **Layered Memory** (session, preference, behavioral, semantic)
- **Fashion Knowledge Graph** (relational style reasoning)
- **Observability** (distributed tracing, metrics, A/B testing)
