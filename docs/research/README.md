# Research programme

Cirvanna research is evidence-led. Model cards and papers generate hypotheses; matched experiments establish whether a method is useful for Cirvanna.

## AI model evaluation

- [AI model competition and logic-transfer programme](ai-model-competition-and-logic-transfer.md) — governing standard for comparing external systems, identifying the mechanism behind any advantage, independently implementing that principle, and proving it against Cirvanna's frozen baseline.
- [Fashion retrieval challenger benchmark](fashion-retrieval-challenger-benchmark.md) — first executable research priority; compares the pinned FashionCLIP baseline with Marqo and ZooClaw challengers on matched image/text retrieval tasks.
- [Model and dataset candidate register](model-candidate-register.md) — current diligence queue, candidate states, data-rights cautions and next review actions.

## Other research tracks

- [Twin provider pilot scorecard](twin-provider-pilot-scorecard.md) — provider diligence and qualification criteria. A shortlist is not provider approval.
- [Twin provider qualification assessment](../architecture/twin-provider-qualification-2026-11-17.md) — current geometry, appearance, privacy and commercial qualification boundary.

## Evidence discipline

Do not commit customer images, identifiable annotations, account mappings, or raw participant-level traces. Store them only in an approved restricted evaluation workspace. Every performance claim must cite the exact code, model, data, evaluator and runtime versions used.
