Blinded Outfit Review

Rate outfit relevance and whether the candidate conflicts with an explicit exclusion. Candidate order is randomized. System assignment, ranking scores and live rank are not shown.

This version is metadata-only: it does not evaluate visual appeal, garment fit, skin appearance or virtual try-on realism. Do not add names, account IDs, photos or other personal data to review notes; this tool has no free-text notes.
